# Área de trabalho UNIEX

Repositório feito para versionarmos projetos desenvolvidos a partir do UNIEX...

### Para cada projeto, vamos manter o seguinte padrão:

- Manter um README.MD atualizado, com orientações de como executar o projeto e status sobre sua aplicação ( Desenvolvendo/Parado/Largado/Deu ruim)
- Cada pasta a partir desse repositório será um projeto, podendo haver exceções, não precisa ser via de regra, apenas organização.
- Avaliar a escalabilidade de cada projeto, precisando colocá-lo no ar, podemos criar outro repositório apenas para ele afim de manter uma boa infra.
